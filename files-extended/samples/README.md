# cria-files-extended samples

A small tree to point the Files panel at: one file per kind of icon, folders to unfold, and names that a careless command would break (`a name with spaces.txt`, `it's $(x).txt`). `expected.json` says which icon and color each row shows, and what the menu does; the unit tests and the smoke test both read it.

Try the menu on a copy of this folder, not on it: Rename, Move to Trash and Delete change what's on disk.
